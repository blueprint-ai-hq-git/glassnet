**What to send us:**
- A number we can reproduce, with the command you ran and the log it produced.
- A failed experiment. Those are more valuable than successes and get published as-is.
- A readability test: run `explain()` and tell us whether the explanation matched what the model did.

**Response time:** this is a small project run around a full-time schedule. Expect days, not hours. If
something is silently broken, email rather than filing an issue - email is read first.
