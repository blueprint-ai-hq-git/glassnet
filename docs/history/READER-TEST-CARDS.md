# READER TEST CARDS — R4 (is the name enough to understand the neuron?)

**This is the one metric in GlassNet judged by a human, not computed.**
**Official reader: the owner or the external reviewer — NOT the agent**, which wrote
the names and would be circular.

## How to fill this in

Each card below gives a concept's **name** and **10 text windows in random order**.
For each window, mark **Y** if you believe that neuron fires on it, **N** if not.
**Exactly 5 of the 10 do fire** — that is the only hint you get, and it is fair.

Scoring: **8 of 10 correct (0.80) or better = the name is genuinely informative.**
Chance is 5/10. The answer key is in a separate file (`runs/t3/reader_test_key.json`)
— do not open it until you have filled in the cards.
